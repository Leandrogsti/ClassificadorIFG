Modelos e resultados

Comparação dos classificadores que rodam antes da camada de LLM. Os hiperparâmetros são escolhidos pelo F1 macro na validação, nunca no teste: olhar o teste para escolher a configuração vaza informação e infla o resultado.

torch{{ ambiente.torch }}

Dispositivo em uso{{ ambiente.dispositivo }}

O treino roda igual nos dois: --dispositivo auto usa a GPU quando existe e cai para CPU quando não. Em CPU é bem mais lento, mas o resultado é o mesmo, o que permite reproduzir o trabalho em qualquer máquina.

Como rodar o treino

# sorteia a divisão e compara os 6 modelos na tarefa binária
python rodar_treino.py --dividir --tarefa violencia

# as três tarefas em sequência
python rodar_treino.py --tarefa todas

# força CPU (máquina sem placa de vídeo)
python rodar_treino.py --tarefa violencia --dispositivo cpu

# uma combinação só, para inspecionar rápido
python rodar_treino.py --tarefa motivacao --modelo bertimbau-base --grade 1

Cada execução grava uma linha com as métricas no banco, e os pesos do melhor modelo de cada tarefa vão para modelos/<tarefa>. Falhas (falta de memória na GPU, por exemplo) também são registradas — um modelo que não cabe na placa é resultado, não motivo para omitir a linha.
